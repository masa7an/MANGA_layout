# MANGA_layout（漫画レイアウタ）

クリスタや forge で描いた画像を貼り込み、**コマ割り・フキダシ・セリフ配置**を行うためのエディタ。
用途は**ネーム／下書き**で、清書・仕上げはクリスタ側で行う。決まったレイアウトを画像で書き出し、
作画の下敷きにするところまでを受け持つ。

- 発表先はウェブ漫画で、印刷はしない。単位は**ピクセル（px）**で、dpi を数字で指定させることはしない
- やらないこと: ブラシ / レイヤー効果 / PSD 入出力 / AI 生成 / トーン / ベクター / フィルター / 色調補正 / 印刷入稿品質の出力

作るものの詳細と「なぜそうしたか」は [要件定義.md](要件定義.md) にある。この README は**動かして使うため**の説明。

---

## 動かすまで

### 初回だけ（新しい PC で clone したとき）

```bash
_setup_env.bat
```

Python 3.12 で `venv/`（Python の仮想環境）を作り、必要なパッケージを入れる。
すでに `venv/` があるときは作り直さず、パッケージの確認だけを行う。

### 起動

```bash
run.bat
```

作品フォルダを渡すと、それを開いた状態で始まる。

```bash
run.bat samples\basic
```

コマンドから直接動かす場合は、**必ず venv の python.exe を指定する**。

```bash
./venv/Scripts/python.exe main.py
```

## 使い方の流れ

1. `P`（コマ追加）でコマを置き、`H` / `J` で分割してコマ割りを作る
2. コマをダブルクリックして中に入り、`Ctrl+V` で画像を貼る（`Ctrl+Shift+F` でコマに合わせて埋める）
3. `B` / `G` / `W` でフキダシ、`T` でセリフを置く。`F2` で文字を打つ
4. `Ctrl+Shift+N` でページを足し、`PageUp` / `PageDown` で行き来する
5. `Ctrl+S` で保存し、`Ctrl+E` で画像に書き出す

書き出し先は**作品フォルダの中の `export/`** で固定。ファイル名は `p01.png` / `p01.jpg` のように、
総ページ数に合わせて桁を揃える。形式（PNG / JPG）と画像サイズ（117% / 100% / 75% / 50%）は
書き出しの窓で選ぶ。既定は PNG の 117%。

## 作品フォルダの中身

作品は1個のファイルではなく**フォルダ**として保存する。

| 名前 | 中身 |
|---|---|
| `project.json` | 作品の本体（ページ、コマ、フキダシ、セリフ） |
| `assets/` | 貼り込んだ画像。ファイル名は中身から作られるので、手で触らない |
| `backup/` | `project.N.json`（保存のたびに退避・5世代）と `autosave.N.json`（5分ごとに退避・3世代） |
| `export/` | 書き出した PNG / JPG |

「開く」では `project.json` を選ぶ。復元は `backup/` の中身を `project.json` に手で置き換えて行う
（アプリ側に復元の窓は用意していない）。

## 外部設定ファイル

**このリポジトリの `data/settings.json`。** アプリを一度起動すると、無ければ雛形が作られる。

ここに入れるのは**この PC でのこのアプリの好み**で、作品に属するもの（ページの大きさ、綴じ方向）は
`project.json` 側にある。`data/` は git 管理外なので、`F:` のような片方の PC にしか無いドライブを
書いても、もう1台へは同期されない。

```json
{
  "format_version": 1,
  "default_parent_dir": "F:\\2025_e\\a漫画用\\帰省\\下書き",
  "autosave_interval_sec": 300,
  "jpg_quality": 90,
  "rough_opacity": 0.4
}
```

| 項目 | 既定 | 受け付ける範囲 | 何が変わるか |
|---|---|---|---|
| `default_parent_dir` | `null` | フォルダのパス | ファイルの窓が始まる場所。作品フォルダそのものではなく、その**1つ上**を指す。`null` ならドキュメントフォルダ |
| `autosave_interval_sec` | `300`（5分） | 5〜3600 秒 | 自動バックアップの間隔。**変えたらアプリを開き直す**（起動時に1度だけ読む） |
| `jpg_quality` | `90` | 1〜100 | JPG で書き出すときの品質（→ 下記）。書き出しの窓には出さない |
| `rough_opacity` | `0.4` | 0.05〜1.0 | ラフ（下敷き）の濃さ。0 に近いほど薄い |

書き換えるときの決まりごと。

- **JSON なので、Windows のパスは `\` を2つ重ねて書く**（`F:\\2025_e\\...`）
- 範囲の外の値・数でない値は、**黙って既定値に戻して動く**。打ち間違いで起動しなくなることはない
- 知らない項目は読み飛ばすので、メモを兼ねた行が残っていても構わない
- `autosave_interval_sec` 以外は**使う直前に読み直す**ので、アプリを開いたまま書き換えても効く

### JPG の品質について

`jpg_quality` は 0〜100 で、大きいほど高画質・大容量。**100 にする意味はほとんど無い。**
品質ごとのデータ量の目安は次のとおり（品質 100% のときを「1MB」とした場合）。

| 品質 | データ量 | 1MB のとき | 位置づけ |
|---|---|---|---|
| 95% | 約 50〜60% に減る | 約 550KB | 画質は 100% と**全く見分けがつかない**のに、データ量は一気に半分近くまで落ちる |
| 90%（既定） | 約 30〜40% に減る | 約 350KB | プロのカメラマンがウェブで公開する際によく使う、高画質と軽さを両立できる設定 |
| 80% | 約 20〜30% に減る | 約 250KB | 一般的なウェブサイトやブログで最も推奨される設定。画質はきれいに保たれたまま、データ量は4分の1程度まで激減する |

#### なぜ少し下げるだけでこんなに減るのか

JPG は「**人間の目が気づきにくい細かい色の変化**」から順番に、大雑把に間引いていく仕組みだから。
品質 100% から 95% にするだけで、目には見えない不要なデータが大量に削ぎ落とされるため、
画質を落とさずにこれだけのデータ量を削減できる。

## ショートカット

| キー | 動作 |
|---|---|
| `V` / `P` / `H` / `J` / `K` | 道具の切り替え（選択 / コマ追加 / 横に分割 / 縦に分割 / 斜めに縦割り） |
| `B` / `G` / `W` / `T` | フキダシ（丸い / ギザギザ / ふわふわ）/ セリフ。雲と四角はメニューと右クリックから |
| `M` | ビックリマークを置く。ビックリはてなはメニューと右クリックから |
| `F2` / `Enter` | 選択中のセリフを入力する |
| `Ctrl+B` | セリフを太字にする |
| `F7` | セリフを縦書き / 横書きに切り替える |
| `Ctrl+]` / `Ctrl+[` | セリフを大きく / 小さく |
| `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z` | 元に戻す / やり直し（`Ctrl+Y` と `Ctrl+Shift+Z` はどちらも「やり直す」） |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 名前を付けて保存 |
| `Ctrl+N` / `Ctrl+O` / `Ctrl+W` | 新規作成 / 開く / 閉じる |
| `Ctrl+E` | 画像で書き出し |
| `Delete` | 選択中のコマ／画像を削除 |
| `Ctrl+Shift+A` | ページ全面にコマを作る |
| `Ctrl+Shift+N` / `Ctrl+Shift+I` | ページを追加（末尾）/ 挿入（表示中のページの前） |
| `PageUp` / `PageDown` | 前後のページへ |
| `Ctrl+Shift+PageUp` / `Ctrl+Shift+PageDown` | 表示中のページを前後へ動かす（並べ替え） |
| ホイール | 拡大縮小（マウス位置が軸） |
| `+` / `-` | 拡大縮小（画面中心が軸）。`Ctrl` 併用も可 |
| `Ctrl+1` / `Ctrl+0` | 原寸で表示 / ページ全体を表示 |
| スペース+ドラッグ／中ボタン+ドラッグ | 画面移動 |
| `Ctrl+V` | 画像を貼り付け |
| `Ctrl+Shift+F` | 画像をコマにフィット（埋める） |
| ダブルクリック | コマに入って画像を選ぶ |
| 右クリック | 押した場所のものを選び、その場のメニューを出す |
| `Esc` | 画像からコマへ戻る／選択解除 |
| `Shift`+ドラッグ | 等比リサイズ（画像の角のつまみ）／15度刻みの回転（画像の回転つまみ） |

複製に `Ctrl+D` は割り当てていない（「編集 → 複製」と右クリックから使う）。
セリフの入力中は、画面側がキーを1つも横取りしない。
